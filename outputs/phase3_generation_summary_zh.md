# Phase 3 生成实验中文总结

## 已完成什么

两套本地大模型、四种回答方式全部完成：

- 模型：Qwen3-4B-Instruct、Qwen2.5-7B-Instruct
- 方法：Direct、BM25 RAG、BGE-M3 Dense RAG、Hybrid RAG
- 每种条件：309 个测试问题
- 正式回答总数：2472 条
- 成功：2472/2472
- 运行错误：0

## 已经可以确认的结果

检索到正确法条的 top-10 覆盖率如下：

| 方法 | Top-10 正确法条覆盖率 |
|---|---:|
| BM25 | 57.61% |
| BGE-M3 Dense | 68.28% |
| Hybrid | 69.58% |

所以目前可以确认：Hybrid 找到正确法条的能力最好，Dense 第二，BM25 第三。

但这还不能直接说明 Hybrid 的法律回答一定最好。原因是模型可能会：

- 找到了正确法条，却错误理解法条；
- 引用了检索结果中没有的法律规定；
- 把多个法条拼接成错误结论；
- 没有引用法条，但回答本身是正确的。

## 下一步怎么判断

下一步做人工/规则复核，不是继续下载模型。重点比较：

1. Direct 和 Hybrid 哪个法律结论更正确；
2. 回答引用的法条是否真的支持结论；
3. 是否出现没有证据支持的法律断言；
4. Hybrid 是否比 Dense、BM25 少错误；
5. 两个模型是否得出相同结论。

判断规则：

- 如果 Hybrid 的引用错误率最低，就用 Hybrid 进入 Phase 4 定向修复；
- 如果 Dense 和 BM25 各有优势，就保留两者作为对照；
- 如果 RAG 没有比 Direct 更好，就先修改证据筛选或 prompt，不进入大规模修复。

目前不应仅凭回答长度、运行速度或“出现了法条名称”判断法律正确性。
